## How I work

I build with AI coding agents and stay accountable for every line that ships. Each task
starts as a written plan with a done-when; the agent works from it, and I review the
diff, run it, and merge it myself. Nothing lands without a branch, a pull request, and a
green CI run — formatters, linters, type checks, and the test suites in all three
languages. I don't commit code I can't explain. The hard part is no longer writing
code; it's trusting it, and trust is something you build with verification.
